About Optimal Binary Search Tree

An Optimal Binary Search Tree (OBST) is a binary search tree designed to minimize the expected search cost based on the search probabilities of the keys.

Objectives

  • Understand the concept of an Optimal Binary Search Tree.
  • Apply Dynamic Programming to solve the problem.
  • Find the minimum expected search cost.
  • Identify the optimal root key.

Applications

  • Database searching
  • Dictionary applications
  • Information retrieval systems
