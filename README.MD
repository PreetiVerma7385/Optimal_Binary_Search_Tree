Optimal Binary Search Tree (OBST)

Aim

To study and explain the concept of an Optimal Binary Search Tree (OBST), and how dynamic programming is used to construct a search tree with minimum expected search cost based on key search probabilities.

Introduction

An Optimal Binary Search Tree is a binary search tree designed to minimize the expected search cost based on the search probabilities of keys.

Objectives

To understand Binary Search Trees and the idea of an optimal search structure.
To learn how search frequencies or probabilities affect the arrangement of keys.
To explain the role of dynamic programming in finding an optimal BST.
To understand the expected search cost using key probabilities and depth.
To examine an example of an optimal BST and identify its root and subtrees
To explore applications of OBST in dictionaries, databases, and lookup systems.

Technologies Used

- HTML
- CSS
- JavaScript
- Dynamic Programming

Applications

- Database searching
- Dictionary applications
- Information retrieval systems

Conclusion

The project demonstrates how Dynamic Programming can construct an Optimal Binary Search Tree with minimum expected search cost.
